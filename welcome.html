Duplicate Tab is ready

Click the toolbar icon to duplicate the current tab, or use a keyboard shortcut.

Duplicate tab
Alt + Shift + D
Close other tabs
Alt + Shift + W

Prefer Ctrl + D?

You can have it, but only by assigning it yourself. Chrome does not let an extension claim that combination out of the box, because it already belongs to “Bookmark this page”.

Open the shortcuts page, find Duplicate Tab, and record Ctrl + D (Command + D on macOS) over the default.

Heads up: this takes Ctrl + D away from bookmarking, and Chrome offers no way to move bookmarking somewhere else. You can still bookmark from the star icon in the address bar or the Bookmarks menu.

Close other tabs

Closes every tab in the current window except the active one. Pinned and grouped tabs are always spared, and closed tabs can be restored one at a time with Ctrl + Shift + T.

Free and open source. No analytics, no tracking, no network requests. github.com/zertosh/duplicate-tab
